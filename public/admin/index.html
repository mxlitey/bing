数据格式说明 & AI转换提示词

导入格式示例

{
  "data": {
    "2024": {
      "202401": {
        "zh-CN": [
          { "date": "20240101", "title": "...", "copyright": "...", "image_url": "...", "description": "..." }
        ],
        "en-US": [...]
      },
      "202402": {...}
    }
  }
}

字段说明

  • data - 根字段
  • 年份 - 4位数字，如 2024
  • 月份 - 6位数字，如 202401
  • 市场 - 市场代码，如 zh-CN、en-US
  • date - 8位日期，如 20240101（必需）
  • title - 标题（可选）
  • copyright - 版权信息（可选）
  • image_url - 图片URL（可选）
  • description - 描述（可选）

4. 每条数据必须包含date字段(8位日期YYYYMMDD)
5. 其他字段可选：title、copyright、image_url、description
